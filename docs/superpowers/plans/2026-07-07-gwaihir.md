# Gwaihir Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/gwaihir`, a read-only lens that gathers Outlook mail and Microsoft Teams messages into one combined "what needs me?" brief.

**Architecture:** A pure prompt-skill (`skills/gwaihir/SKILL.md`, no shell code) that orchestrates primitives already in the tree — the `outlook_email_search` connector tool for mail, `vor-teams-poll.sh` for Teams, `outlook-classify.sh` for mail override rules. It surfaces only; the acting verbs stay with `/triage` and `/vor`. It is the communications analog of `/palantír`.

**Tech Stack:** Markdown skill file. No new hooks, no `settings.json` change (all called hooks are already allowlisted by `/triage` and `/vor`). Propagated to config roots via `/install`.

## Global Constraints

- **No new hook, no code.** Gwaihir adds only `skills/gwaihir/SKILL.md`. If a task wants to write shell, the design is wrong — stop and re-check.
- **Read-only.** Only the connector `outlook_email_search`, `vor-teams-poll.sh` (GET poller), and `outlook-classify.sh` lookup. No mark-read, move, post, draft-send, or run-stamp.
- **No drafting.** Gwaihir names the Teams threads that want a reply; it does not compose one. Drafting stays `/vor`.
- **No mail account-switching.** Default Outlook account only. Non-default → `/triage <account>`.
- **Classification is `/triage` §2's, referenced not restated.** Gwaihir points at `/triage`'s Worth-a-look rules as the single source of truth; it must not copy the prose.
- **Verification is a dry-run trace**, not a unit test — this is a prompt-skill. Each task's "test" is: given the named sample input, the render/behavior the skill prose produces must match the named expectation. The implementer reads the prose and traces it by hand.

# Gwaihir — the Windlord's Brief

Gwaihir bears word in from afar. It gathers what arrived in Outlook mail and
Microsoft Teams, lays the few items that need a human eye before you in one
view, and points to `/triage` and `/vor` for the acting. **It reads and
surfaces. It never acts.**

## Arguments

`/gwaihir [channel] [hours]` — order-independent, both optional.

- `mail` → mail channel only.
- `teams` → Teams channel only.
- A bare integer → the mail lookback window in hours (default `24`). Mirrors
  `/triage`. Ignored when scope is `teams` — Teams has no window; its poller
  reads the delta since its last cursor.
- No args → both channels, 24h mail window.

If the integer is non-numeric or absent, default to `24` without prompting.

Examples:

- `/gwaihir` — both channels, 24h mail window
- `/gwaihir mail 48` — mail only, 48h
- `/gwaihir teams` — Teams only
- `/gwaihir 6` — both channels, last 6h of mail
